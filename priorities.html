Run Order Planner

Prioritize a chosen shipment date • plan in full lots • update parts as you run

Single-file HTML · offline · saved in this browser

1. Paste your shipment report

Accepts your Excel tab-separated report or the Markdown table format. Quantity is good inventory; each date column is daily shipment demand. Parentheses show cumulative shortages in the original report, which the planner recalculates.

2. Choose how far ahead to cover

Pick the last shipping date to include, or choose the first 2 or 5 dates from the report. Each option counts shipment-date columns, not calendar days—so weekends or missing dates are skipped. Earlier requirements are always included in cumulative shortages.

Quick selection
Import a report to select your shipment coverage date.

3. Recommended run order & adjustable lots

Recommended lots covers shipments through your chosen date only. Use Set planned lots to cover cutoff to fill in a recommended plan, then change any number with +/− or by typing. The green number beside the lots is the equivalent number of parts. Click Complete 1 lot each time a full lot is finished: remaining lots decrease and available good inventory increases. The rows stay in exactly the same order while you complete lots, even when their priority changes. Click Update Run Order when you want to re-rank them.

The selected cutoff limits recommendations, not the displayed shipment coverage table. Later shipments remain visible but are not automatically planned. Planned production is assumed ready before the relevant shipment; this tool does not yet account for cycle times, changeovers, inspection release, or truck pickup cutoffs. Confirm actual available inventory before using the plan.

4. Shipment coverage — selected dates highlighted

Projected balances subtract shipments cumulatively from inventory plus all remaining planned production. Red = shortage. Blue headers = dates included in your priority window; grey headers = later dates. This is a quantity check, not a time-based guarantee.
